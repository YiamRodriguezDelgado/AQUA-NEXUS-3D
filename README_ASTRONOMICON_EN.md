# AQUA·NEXUS 3D — Team Astronomicon

**NASA Space Apps Challenge 2026 — Be An Earth System Trend Detective!**

A bilingual (English / Spanish) interactive prototype for exploring precipitation and illustrative flood scenarios in Uruguay.

## Run locally
On Windows, extract the archive and run `INICIAR_AQUA_NEXUS.bat`. Open http://127.0.0.1:8688/. Use **EN / ES** in the header to switch languages.

## Scientific limitations
NASA POWER observations are retrieved on demand and are distinct from simulated rainfall and illustrative flood areas. The map is artistic, not georeferenced. Synthetic flood projections must not be used for real-world flood warnings. Historical flood-displacement figures are from public SINAE reports and are not satellite-derived inundation polygons.
